# Petal & Bloom — Flower Gallery

A responsive flower gallery assignment made with HTML, CSS, and JavaScript. Browse six blooms, filter by collection, search by name, and open a detail card for each flower.

## Run the project

1. Download and extract `Flower_Gallery_Project.zip`.
2. Open the `flower-gallery` folder.
3. Double-click `index.html` to view the gallery in a browser.

The gallery uses Google Fonts and flower photos from Unsplash, so an internet connection is needed for those images and fonts. The page itself runs locally without installing anything.

## Upload to GitHub

1. Create a new repository on [GitHub](https://github.com/new), for example `flower-gallery`.
2. Keep **Add a README file** unchecked because this project already includes one.
3. Open the new repository and choose **uploading an existing file**.
4. Drag the contents of the `flower-gallery` folder into the upload area.
5. Add a commit message such as `Add flower gallery assignment` and choose **Commit changes**.

## Files

- `index.html` — page content and gallery cards
- `style.css` — layout, colors, responsive styling, and animations
- `script.js` — category filters, search, and flower detail dialog

## Assignment summary

**Objective:** Build an attractive, responsive gallery that introduces flower varieties.

**Features:** Responsive layout, category filtering, live search, accessible detail dialog, and a short description for each flower.

**Technologies:** HTML, CSS, and vanilla JavaScript.
